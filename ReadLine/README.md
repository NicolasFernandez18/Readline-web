# 🚀 RedLine.web - Despliegue en Vercel

Este repositorio contiene el código fuente de **RedLine.web**.

## Pasos para publicar la web en Vercel:

1. **Subir a GitHub:**
   - Creá un nuevo repositorio público en GitHub llamado `redline-web`.
   - Subí los archivos `index.html` y `README.md`.

2. **Conectar con Vercel:**
   - Entrá a [Vercel.com](https://vercel.com) e inicia sesión con tu cuenta de GitHub.
   - Hacé clic en **"Add New..."** -> **"Project"**.
   - Selecciona el repositorio `redline-web`.
   - Presioná **"Deploy"**.

3. **¡Listo!**
   - Vercel te dará una URL en segundos (ejemplo: `redline-web.vercel.app`).
   - Cada vez que hagas un cambio o *commit* en Git, Vercel actualizará tu sitio web automáticamente.
