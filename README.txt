REDLINE.WEB — LANDING PAGE

Archivos:
- index.html
- style.css
- script.js

Cómo usar:
1. Descomprimí el ZIP.
2. Abrí index.html para verlo en tu navegador.
3. Para subirlo a GitHub + Vercel, subí los 3 archivos al repositorio y conectalo con Vercel.
4. Cambiá el mail hola@redline.web por tu mail real en index.html.

Nota: las tipografías se cargan desde Google Fonts con conexión a internet. Si querés trabajar 100% offline, descargá las fuentes y reemplazá el enlace.

Los proyectos Blackline Barber, Nova Studio y Volt Garage son CONCEPT PROJECTS, no clientes reales.
